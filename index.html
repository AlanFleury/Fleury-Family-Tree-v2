GEDCOM

Export a standards-style GEDCOM 5.5.1 file for use with other genealogy software. Import can be added later without changing your internal IDs.

Your Fleury Archive remains the master database. GEDCOM is an interoperability copy.

Backup & portability

Recommended: keep a dated JSON backup after every significant research session. Exported backups contain the complete family database and should be stored securely.
