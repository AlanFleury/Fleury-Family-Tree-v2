GEDCOM

Export a standards-style GEDCOM 5.5.1 file for use with other genealogy software. Import can be added later without changing your internal IDs.

Your Fleury Archive remains the master database. GEDCOM is an interoperability copy.

Backup & portability

Recommended: keep a dated JSON backup after every significant research session. Exported backups contain the complete family database and should be stored securely.

Family access

Administrators can manage family-member roles in Firebase. The app uses three roles: admin, editor, and viewer.

For the first setup, create your own users/<your Firebase UID> document in Firestore with role: "admin". After that, the app can be used to manage the family database.

Initial database import

Choose your existing Fleury JSON backup to upload the 120-person database into the private Firestore archive. This file is used only for migration and is not stored on the public website.
