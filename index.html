GEDCOM import & export

GEDCOM files (.ged) let you transfer genealogy data between family-tree programs. Export a backup before importing. Import adds people and recorded family links; it does not delete existing records.

Choose a GEDCOM file to check it before importing.

Administrator-only safety tool. Find blank-name or “(Unnamed)” records, review each record's ID and linked relationship count, then select only the records you intend to remove. Nothing is deleted during scanning or preview.
